# 系统架构总览（core.P0）

## 1. 核心概念

- **蓝图（Blueprint）**：一个可视化工作流，由节点和连线组成，是**有向无环图（DAG）**。
- **节点（Node）**：工作流的最小单元，本质 = **系统提示词 + 输入口（inputs）+ 输出口（outputs）**。
- **智能体节点**：一个独立的 Pi 会话（小型 agent），有自己的系统提示词、模型、上下文；输入内容作为用户消息喂给它，输出为最终回复文本。
- **自定义节点**：通过 JSON 声明（智能体行为）或 JS 实现（函数行为）扩展的节点。
- **连线（Edge）**：把上游节点的输出口连接到下游节点的输入口，传输数据值。

## 2. 执行模型

- **拓扑排序**：按依赖关系确定执行顺序；有上游依赖的节点等待上游完成后才运行。
- **自动并行**：同一层内互不依赖的节点**同时执行**（并行运行多个智能体会话）。
- **调试运行**：可以只运行选中的节点；其上游使用上一次完整运行的结果缓存，无缓存则报错提示先运行完整蓝图。
- **中止**：运行中可整体中止，所有进行中的智能体会话被取消。

## 3. 数据流类型

类型注册表（未来可扩展声音/视频）：

| 类型 | 含义 | 传输方式 |
|------|------|---------|
| `text` | 纯文本 | 文本内容 |
| `image` | 图片 | 文件路径（预览时渲染缩略图） |
| `file` | 文件 | 文件路径 |
| `path` | 路径 | 路径字符串 |
| `any` | 任意 | 兼容所有类型 |

连线规则：输出类型必须与输入类型一致，或任意一方为 `any`。

## 4. 目录布局

| 位置 | 用途 |
|------|------|
| `~/.pi/nodes/` | 用户级自定义节点（JSON 声明 + JS 实现） |
| `<项目>/.pi/nodes/` | 项目级自定义节点 |
| `~/.pi/nodes-docs/` | 本说明书文档集 |
| `~/.pi/blueprints/` | 已保存的蓝图（JSON） |

## 5. 内置节点类型

| 类型 | 说明 |
|------|------|
| `input` | 输入节点：提供初始文本/文件，无输入口，一个输出口 |
| `output` | 输出节点：收集最终结果，可接受多个输入口 |
| `agent` | 通用智能体节点：可配置系统提示词/模型/思考级别/上下文上限 |

## 6. 与 AI 协作

- AI 通过 `create_node` 创建节点、`run_blueprint` 运行蓝图、`view_node_library` 查看节点库。
- 用户在多智能体协作场景中可以直接在画布窗口操作，也可以在聊天中让 AI 规划并创建蓝图。
