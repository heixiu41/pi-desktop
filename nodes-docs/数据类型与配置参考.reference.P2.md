# 数据类型与配置参考（reference.P2）

## 1. 类型注册表

| 类型 | 说明 | 备注 |
|------|------|------|
| `text` | 纯文本 | 最常用 |
| `image` | 图片 | 传输路径；画布中渲染缩略图预览 |
| `file` | 文件 | 传输路径 |
| `path` | 路径 | 字符串路径 |
| `any` | 任意类型 | 兼容所有 |

扩展类型：未来加入 `audio`、`video` 等，注册方式与现有类型一致。

## 2. 连线兼容规则

- 输出类型 == 输入类型 → 允许
- 任一端为 `any` → 允许
- 其他 → 拒绝（画布上会给出提示）

## 3. 智能体节点配置项

| 配置 | 类型 | 生效情况 |
|------|------|---------|
| `systemPrompt` | 文本 | ✅ 生效：覆盖该节点的系统提示词 |
| `model` | {provider, id} | ✅ 生效：指定模型；缺省用全局默认 |
| `thinkingLevel` | off/low/medium/high 等 | ✅ 生效：指定思考级别 |
| `maxContext` | 数字（token） | ✅ 近似生效：设为上下文压缩阈值 |
| `temperature` | 数字 | ⚠️ 预留：SDK 暂不支持，存储但不生效 |
| `tools` | 字符串数组 | ✅ 生效：该节点允许的工具白名单 |

## 4. 智能体节点输入构建

- 每个输入口的内容按 `### 输入「端口名」` 分组，作为一条用户消息
- 多个输入口内容拼接为同一条用户消息
- 输入为 `image` 且提供路径时，自动读取文件并以图片块发送（>10MB 跳过并提示）

## 5. 输出

- 智能体节点输出 = 运行期间累积的完整回复文本（`text` 类型）
- 函数节点输出 = JS execute 的返回值
