# 节点创建示例（example.P2）

## 场景：创建一个"总结智能体"节点

需求：输入一段长文本，输出 100 字以内的中文摘要。

### 方式一：纯声明（智能体节点）

用 `create_node` 工具创建：

```json
{
  "name": "summarizer",
  "label": "文本总结",
  "description": "把输入长文本压缩成 100 字以内的中文摘要",
  "category": "agent",
  "inputs": [{ "name": "text", "type": "text", "label": "长文本" }],
  "outputs": [{ "name": "text", "type": "text", "label": "摘要" }],
  "systemPrompt": "你是文本总结助手。把输入文本压缩成 100 字以内的中文摘要，直接输出摘要正文，不要任何解释。",
  "tools": ["read"]
}
```

无需实现文件——运行时它就是一个智能体会话。

### 方式二：声明 + JS 实现（函数节点）

当逻辑确定、无需 LLM 时，用代码实现更省：

```js
// summarizer.js
export default {
  async execute(inputs, config, ctx) {
    const text = inputs.text?.text || "";
    const lines = text.split("\n").filter(Boolean);
    const head = lines.slice(0, 5).join("\n");
    ctx.log(`收到 ${text.length} 字符，输出前 5 行`);
    return { text: { type: "text", text: head } };
  },
};
```

创建时把 `implementationCode` 传给 `create_node`，并保持 JSON 声明中的 `name` 与 JS 文件名一致。

## 常见错误（避免）

| 错误 | 结果 |
|------|------|
| name 含大写或空格 | create_node 拒绝 |
| 端口 type 不在注册表 | create_node 拒绝 |
| inputs/outputs 为空 | create_node 拒绝 |
| JS 缺少 `export default` | create_node 拒绝 |
| 返回的端口名与 outputs 声明不一致 | 运行时报错 |

## 如何验证

1. `view_node_library` 确认节点在列表
2. 在画布节点库中添加该节点，连线运行
3. 或用 `run_blueprint` 直接运行含该节点的蓝图 JSON
