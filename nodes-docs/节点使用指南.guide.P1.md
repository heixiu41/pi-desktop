# 节点使用指南（guide.P1）

## 1. 打开画布

- 主窗口侧边栏点「节点」→ 打开画布窗口（独立窗口，可停靠回主窗口）

## 2. 画布操作

| 操作 | 方式 |
|------|------|
| 平移画布 | 左键拖拽空白处 |
| 缩放 | 鼠标滚轮 |
| 框选 | Shift + 左键拖拽空白处 |
| 多选 | Shift + 点击节点 |
| 移动节点 | 拖拽节点标题栏（选中组一起移动） |
| 连线 | 从输出口拖到输入口（类型需兼容） |
| 删除连线 | 点击连线选中后按 Delete |
| 删除节点 | 选中后按 Delete（连线一并删除） |
| 配置节点 | 双击节点打开配置面板 |

## 3. 节点配置面板（双击节点）

- 通用：标题
- 智能体节点：系统提示词、模型、思考级别、温度（预留，暂不生效）、最大上下文长度（token，触发压缩）
- input 节点：内容（文本或文件路径）
- 自定义节点：按声明的配置字段显示

## 4. 运行

- **▶ 运行**：拓扑排序执行整张蓝图；无依赖分支自动并行
- **◉ 调试运行**：仅运行选中的节点；上游用上次运行的缓存结果，无缓存则提示先完整运行
- **■ 停止**：中止当前运行，所有智能体会话取消

## 5. 节点状态

| 状态 | 显示 |
|------|------|
| 等待 | 灰色边框 |
| 运行中 | 蓝色高亮 + 进度条 + 流式文本预览 |
| 完成 | 绿色边框，可点击展开完整输出 |
| 失败 | 红色边框 + 错误信息 |

## 6. 蓝图管理

- **＋ 新建**：清空画布
- **💾 保存**：保存到 `~/.pi/blueprints/`
- **加载**：下拉选择预设或已保存蓝图
- 预设：规划→执行→审查链 / 并行调研 / 代码审查流水线

## 7. 在聊天中使用

- 让 AI 创建节点：`create_node`
- 让 AI 运行蓝图：`run_blueprint`（默认等待完成并返回各节点结果）
- AI 会先阅读本说明与 create.P0 规范再行动
